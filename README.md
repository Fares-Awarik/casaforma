## About
A concept landing page for a premium furniture brand —
built to demonstrate a modern showcase for home and
commercial furniture, with WhatsApp-first ordering,
category browsing, and delivery information.

## Features
- WhatsApp-integrated inquiry flow (no forms)
- Category & featured product sections
- Delivery zones + commercial/bulk focus
- Fully responsive single-page design

## Tech Stack
HTML · CSS · JavaScript · GitHub Pages
